# Testudio++

Расширение для VS Code, которое собирает тесты проекта на CMake в панели Testing, запускает их и позволяет создавать и править кейсы с входными данными прямо в редакторе.

Автор: Сабуров Даниил Денисович, группа M3109. Лабораторная работа №3 по дисциплине «Инструментальные средства разработки ПО».

## Возможности

- Дерево тестов в панели Testing: группа «Кейсы testdata» (кейсы данных) и группа «Тесты C++» (тесты ctest по наборам, клик по тесту открывает его код). Пустая группа не показывается. Запускать можно всё сразу, группу или один тест.
- Карточка кейса: имя, статус, код возврата, аргументы, входные файлы, ожидаемый и фактический вывод рядом.
- Кнопка «Diff» для упавшего кейса открывает встроенное сравнение ожидаемого и фактического вывода.
- Создание и правка кейса формой в той же карточке, имя и обязательные файлы проверяются до записи на диск.
- Кнопка «Принять фактический вывод» заменяет `expected.txt` фактическим выводом после подтверждения.
- Переименование и удаление кейса из карточки, удаление ещё и из дерева.
- Нулевые байты, `\r` и байты вне UTF-8 видны в карточке как `\0`, `\r` и `\xNN`.
- Команды «Testudio++: Настроить проект» (`cmake -S . -B build`) и «Testudio++: Собрать проект» (`cmake --build`) запускаются из палитры, дерево обновляется после них и само, когда меняется список тестов ctest.

## Формат кейса

Кейс это папка в `tests/testdata/` с номером в начале имени, например `04_OnlyNewlines`. В ней лежат `args.txt` (аргументы по одному на строке), `expected.txt` (ожидаемый вывод) и входные файлы программы. Строка `{dir}` в `args.txt` и `expected.txt` означает путь к папке кейса.

```text
tests/testdata/04_OnlyNewlines/
  args.txt        {dir}/input.txt
  expected.txt    3 0 3 {dir}/input.txt
  input.txt
```

Кейс пройден, если программа завершилась с кодом 0, а вывод побайтово совпал с `expected.txt`. Программа запускается без оболочки и с пустым вводом в корне открытой папки. Не уложилась в таймаут, значит кейс упал.

## Установка и запуск

Нужны VS Code 1.100 или новее, а для группы «Тесты C++» и сборки ещё CMake и ctest. Поддерживаются macOS и Linux.

Из готового файла:

```bash
code --install-extension testudio-0.1.0.vsix
```

Из исходников:

```bash
git clone https://github.com/wFeeL/Testudio.git
cd Testudio
npm install
npm run compile
```

Откройте папку Testudio в VS Code и нажмите F5, откроется окно с подключённым расширением. Файл `.vsix` собирается командой `npx vsce package`.

Расширение включается, когда в корне открытой папки есть `CMakeLists.txt`. Если проект ещё не собран, выполните команды «Настроить проект» и «Собрать проект» (или `cmake -S . -B build` и `cmake --build build` вручную), потом откройте панель Testing. Новый кейс создаётся правым кликом по группе «Кейсы testdata» или командой «Новый кейс» из палитры, в том числе когда папки с кейсами ещё нет. Тестируемую программу плагин спросит при первом запуске кейса, сменить её можно командой «Testudio++: Выбрать тестируемую программу».

## Настройки

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `testudio.testdataPath` | `tests/testdata` | каталог с кейсами относительно корня открытой папки |
| `testudio.buildDirectory` | `build` | каталог сборки для `ctest` и `cmake --build` |
| `testudio.executablePath` | не задан | тестируемая программа; если путь не задан или файла нет, при первом запуске кейса откроется выбор файла |
| `testudio.cmakePath` | не задан | путь к `cmake` или его имя без `/`; если пусто, поиск в `PATH`, затем в `/opt/homebrew/bin`, `/usr/local/bin`, `/Applications/CMake.app/Contents/bin` |
| `testudio.ctestPath` | не задан | то же для `ctest` |
| `testudio.timeoutSeconds` | `10` | таймаут запуска одного теста в секундах |

## Ограничения

- Windows не проверялся.
- Поддерживается одна папка рабочей области, `CMakeLists.txt` должен лежать в её корне.
- Если в `files.watcherExclude` исключён каталог сборки, дерево после сборки само не обновится, нажмите кнопку обновления в панели Testing.
- Править в форме можно только обычный текст: корректный UTF-8 без нулевых байтов и без `\r`, не больше 100000 байт. Остальные файлы остаются прежними.
- Тесты C++ плагин только показывает и запускает. Проект он не собирает перед запуском и `CMakeLists.txt` не меняет.
